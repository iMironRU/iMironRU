## 📚 Книги и материалы

Пишу про 1С для разработчиков — и для тех, кто приходит на платформу с других стеков.

- **[Дерево метаданных 1С](https://github.com/iMironRU/1c-metadata-tree-book)** — Книга-учебник для новичков: учимся читать дерево метаданных 1С без программирования, понимать бизнес-логику конфигураций и проектировать свои. Сквозной пример — фирма «Канцтовары». _(книга, в работе)_
- **[Чтение данных. Язык запросов 1С](https://github.com/iMironRU/chtenie-dannyh-zaprosy)** — Вторая книга серии. Как читать данные на платформе 1С — от простых выборок до сложных запросов с пакетами, временными таблицами и виртуальными таблицами регистров. _(книга, в работе)_
- **[Чтение форм 1С](https://github.com/iMironRU/1c-forms-reading)** — Третья книга трилогии «Чтение 1С» — про управляемые формы, командный интерфейс и чтение интерфейса как разговора системы с пользователем. Сквозной пример — фирма «Канцтовары». _(книга, черновик)_
- **[1С как иностранный язык](https://github.com/iMironRU/1c-semantic-reading)** — Учимся читать код 1С осмысленно, а не как набор синтаксиса. Новый подход к пониманию платформы для тех, кто пришёл с других стеков. _(книга, черновик)_
- **[1С-разговорник](https://github.com/iMironRU/1c-razgovornik)** — Сравнительный справочник синтаксиса и архитектуры 1С для разработчиков с опытом в Python, JavaScript или C#. Параллельные примеры: «вот так на 1С — вот так на привычном языке». _(справочник, в работе)_
- **[Установка 1С:Предприятие](https://github.com/iMironRU/install-1c)** — Пошаговое руководство по установке платформы 1С:Предприятие — для тех, кто впервые ставит её на свой компьютер или сервер. _(руководство, в работе)_
- **[Что происходит, когда ты кликаешь в 1С](https://github.com/iMironRU/what-happens-when-click-1c)** — Технический лонгрид о внутреннем устройстве платформы 1С — в духе what-happens-when Алекса Гейнора, для разработчиков, переходящих с других стеков. Готовы части 0, I, II, III, IV; части V–IX в работе. _(лонгрид, в работе)_
